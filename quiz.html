基本概念

1. SD モジュールの中心的な成果物は何か？

販売伝票（引合／見積／受注／納入／請求）
品目伝票と在庫
会計伝票
製造指図
答え A。SD は販売伝票を担当します。品目伝票は MM が出庫過転記時に生成し、会計伝票は FI が請求書転記時に生成します。
基本概念

2. どのステップで実際に在庫が減りますか？

受注伝票を保存
出荷伝票を登録
納入の出庫過転記（PGI、移動タイプ 601）
請求書の転記
答え C。受注伝票は約束にすぎません。納入伝票は準備をするだけです。出庫過転記（移動タイプ 601）で初めて品目伝票が生成され、在庫が減少します。
基本概念

3. 「販売エリア」はどの 3 つのキーで構成されますか？

販売組織 + 会社コード + プラント
販売組織 + 流通チャネル + 製品部門
会社コード + 流通チャネル + 販売事務所
販売組織 + 販売事務所 + 販売グループ
答え B。販売エリア Sales Area = 販売組織 + 流通チャネル + 製品部門。得意先／品目の販売ビューと条件レコードの組織キーです。
基本概念

4. 請求書の転記（リリース）時に生成される会計伝票は通常どれですか？

借方 収益 / 貸方 得意先売掛金
借方 得意先売掛金 / 貸方 収益 + 売上税
借方 在庫 / 貸方 買掛金
会計伝票を生成しない
答え B。請求書のリリースで FI 伝票を生成：借方 得意先売掛金（税込）、貸方 販売収益（正味価額）と売上税。
基本概念

5. 次のうち、誤っている記述はどれ？

価格は条件レコードに登録する
1 つの会社コードに複数の販売組織を持てます
納入伝票の登録時に在庫が減少する
1 つの得意先に複数のパートナ役割を持てます
答え C。納入伝票の登録時は在庫は変わりません。在庫が減るのは出庫過転記の時だけです。ほかの記述はすべて正しいです。
組織

6. 販売組織を会社コードに割り当てる意味は？

販売組織がどの会計主体に属するかを決定
販売組織にどの流通チャネルがあるかを決定
出荷プラントを決定
得意先の番号範囲を決定
答え A。販売組織と会社コードは多対一です：この販売取引の収益がどの会社コードの勘定に計上されるかを決定します。

7. 出荷ポイント（Shipping Point）の役割は？

価格を決定
出荷の起点を決定。プラントとは多対多
収益勘定の決定
請求タイプを決定
答え B。出荷ポイントは出荷場所を決定します（教材例：Z999 颐宁装运点）。プラントとは多対多の関係です。

8. ピッキング保管場所の決定条件のうち、教材で有効にしているのはどれですか？

出荷ポイント + プラント（+ 保管条件）
得意先＋品目
販売組織 + 製品部門
会社コード + プラント
答え A。カスタマイジングの「ピッキング場所の割当」は出荷ポイント、プラント、保管条件で決定されます。教材シナリオでは前の 2 つだけを有効にします。

9. 販売事務所（Sales Office）の主な用途は？

税コードを決定

10. 得意先マスタは3階層。販売エリア階層に入るのは？

名称・住所などの一般情報

得意先計算スキーマ、輸送条件、税分類、パートナ役割などの販売データ
リスト

12. 販売価格（PR00）はどこに登録しますか？

品目マスタの販売ビュー
得意先マスタ
条件レコード（VK11）
受注伝票で手入力

マスタ

13. 2つの品目を別々の売上収益勘定に仕向けるには、教材ではどうしていますか？

計算スキーマの計算タイプを変更
品目に異なる勘定割当グループを設定する（M1/M2）
得意先コードを変更
販売エリアを変更
答え B。勘定設定では「勘定キー + 品目の勘定割当グループ + 得意先の勘定割当グループ」を使用します。教材では M1 自製品 / M2 取引商品で収益勘定を区別しています。

答え B。勘定グループの項目ステータスが、得意先マスタ画面の表示と必須ルールを決定します。
価格設定

15. 条件技術で「価格をどこから探すか」から「どのスキーマを使うか」までの正しい順序は？

条件タイプ → 条件テーブル → 計算スキーマ → アクセス順序
条件テーブル → アクセス順序 → 条件タイプ → 計算スキーマ → 計算スキーマ決定
計算スキーマ → 条件テーブル → アクセス順序 → 条件タイプ
アクセス順序 → 計算スキーマ → 条件テーブル → 条件タイプ
答え B。条件テーブルに値を保存 → アクセス順序で優先順位を決定 → 条件タイプで分類 → 計算スキーマでステップを並べる → 計算スキーマ決定でスキーマを選択。

答え B。IMG「計算スキーマの定義と割当」では、販売エリア、得意先計算スキーマ、伝票計算スキーマの 3 つのキーで決定します。

19. 売上税の税額は何によって決まりますか？

品目マスタの価格

販売組織
支払条件
答え B。税コードは得意先の税分類と品目の税分類（+ 国別ルール）で決定され、MWST 条件レコードが税率を提供します。

20. 条件レコードを変更したのに、以前保存した受注伝票が変わらないのはなぜ？

システムキャッシュの問題
伝票はスナップショットであり、マスタの変更は新しい伝票にのみ影響します（または手動での再価格設定が必要）
条件レコードが保存されていない
ユーザ権限の問題
答え B。伝票を保存するとデータが確定し、過去の伝票の追跡が可能になります。変更するには伝票内で再価格設定が必要です。

24. 受注伝票の保存時に「有効在庫なし」のメッセージが出た。正しい理解は？

受注伝票の保存に失敗
そのまま保存を続行でき、確定日が表示されるだけ。後続の出荷前に在庫の補充が必要
ただちに伝票を削除する必要がある
システムが自動で購買する
答え B。所要量確認は標準では保存をブロックしません。教材では MB1C ＋ 501 で期首在庫を入力し、後続の出荷の問題を解決します。

25. 期首在庫を補充するとき、教材ではどの移動タイプを使う？

261

得意先を入力していない

合格したら

能力の検証（単なる試験ではない）
  • ご自身のシステムで自力で一通り実行できる：受注 → 納入 → 出庫過転記 → 請求書 → リリース。
  • 伝票フローで「この請求書がどの受注伝票から来たか」を答えられます。
  • 1 枚の受注伝票の価格の出所と収益勘定の出所を説明できる。
  • 「在庫がない / 請求できない / 価格が空」に遭遇したとき、調査の順序を言える。
